# Fandom State Book

「ファン国家」という構想を記述する、書籍プロジェクトです。

ファン国家とは、生まれた場所ではなく、共感する志によって参加する共同体のこと。
何を解こうとしているのか、なぜそれを目指すのか、どうやって実現するのか。
Gaudiy が積み上げてきた思想を、一貫した言葉で残すために書かれています。

📖 **[日本語版を読む](https://gaudiy.github.io/fandom-state-book/ja/)** / [Read the English edition](https://gaudiy.github.io/fandom-state-book/en/)

---

## この本について

「ファン国家」という言葉は、Gaudiy の内外で頻繁に使われています。
けれど、その説明の仕方は人によって異なり、輪郭が曖昧なままに流通してきました。

ある人はそれを「ファンやクリエイターが報われる社会」として語り、
ある人は「弱い人も弱いままで生きられる社会」として語る。
どちらも間違いではないけれど、どちらも全体像ではありません。

本書は、その状態を解消するために書かれています。
ファン国家とは何か、なぜそれを目指すのか、どのように実現するのか。
一貫した思想として記述することを目的にしています。

## なぜドラフトを公開しているのか

Gaudiy はいま、第二創業ともいえるフェーズにいます。
その節目に、自分たちが何を信じ、何をつくろうとしているのかを、
流れて消えていく言葉ではなく、手元に残る本として届けたいと考えました。

このリポジトリで公開しているのは、その**物理書籍に向けた制作過程のドラフト**です。
完成した本だけを見せるのではなく、書かれていく途中の状態を Web でも読めるようにしています。

本書は最終回答ではありません。現時点における最善の仮説です。
仮説を立て、試し、修正し、また試す。その過程そのものが、ファン国家をつくるということだと考えています。
だから、書き換えの履歴がすべて残る場所に原稿を置いています。

## About this project

**Fandom State Book** describes the idea of a *Fandom State* — a community you join
not by where you were born, but by the vision you share.

This repository holds a working draft of a book Gaudiy is currently producing in print.
Rather than publishing only the finished text, we keep the manuscript in the open as it is written.
It is not a final answer, but our best current hypothesis.

Written and edited by members of Gaudiy. External pull requests are not accepted at this time.
The Japanese edition is the source text; the English edition is generated from it.
